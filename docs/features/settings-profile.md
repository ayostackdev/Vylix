# Settings and Profile Features

This category covers privacy controls, badges, storage management, and profile display.

## Included features

- privacy settings and stealth mode
- linked accounts management
- local storage usage and cache cleanup
- badge display and contribution leaderboard
- academic identity display

## Why it matters

- gives users control over visibility
- supports anonymous or reduced-visibility participation
- helps students manage device storage for offline materials
- adds a lightweight gamification layer
